> 目标读者：**另一个 AI 或开发者**。读完这份文档，应当能够在没有原作者参与的情况下，
> 从源码重新构建、验证、打包、继续迭代这个工具；并且清楚哪些能力已经实测成立、哪些是硬约束。
>
> 最后更新：2026-11-04（图标换成 02-sky，`OneKeySend` / 快捷用语 / 鼠标穿透默认关 / 移除第三方读取组件）

## 1. 这是什么

一个 Windows 桌面工具，给《永恒之塔 2》（AION 2，Steam 客户端）玩家用：

- **实时读游戏内存**里已有的聊天记录（世界/种族/附近/组队等频道），把外文翻成中文，显示在主界面列表 + 游戏上方的悬浮窗；
- **手动翻译**：悬浮窗里一个输入条（F9 调出），输入中文 → 翻成英语/日语等 → 一键复制或直接打进游戏聊天框；
- 悬浮窗可以被 N 卡录制 / OBS / 截图正常拍到（不做 `WDA_EXCLUDEFROMCAPTURE` 排除）。

产物是**单个自包含 exe**（约 72 MB），目标机器无需安装 .NET。

## 3. 从零构建（照抄即可）

### 3.1 环境

- .NET SDK 10（`dotnet --version` ≥ 10.0）
- Windows 10/11 x64
- 可选：Python 3 + Pillow（只在改图标时需要）

### 3.2 编译（开发循环）

```powershell
# 1) 先杀掉正在运行的旧实例，否则 exe 被占用、复制会失败
Get-Process | Where-Object { $_.ProcessName -like 'AION2实时*' } | ForEach-Object { $_.Kill() }

# 2) 编译
dotnet build aion2\src\AionTranslator.UI\AionTranslator.UI.csproj -c Release -v q --nologo
```

### 3.3 发布单文件 exe

```powershell
dotnet publish aion2\src\AionTranslator.UI\AionTranslator.UI.csproj `
  -c Release -r win-x64 --self-contained true `
  -p:PublishSingleFile=true `
  -p:IncludeNativeLibrariesForSelfExtract=true `
  -p:EnableCompressionInSingleFile=true `
  -v q --nologo
```

产物：`src/AionTranslator.UI/bin/Release/net10.0-windows/win-x64/publish/AION2实时翻译.exe`
（开压缩 ≈ 72 MB；不开压缩 ≈ 165 MB）

### 3.4 打包分发

```powershell
$root = "aion2"
Copy-Item "$root\src\AionTranslator.UI\bin\Release\net10.0-windows\win-x64\publish\AION2实时翻译.exe" "$root\dist\AION2实时翻译\" -Force
Copy-Item "$root\dist\使用说明.txt" "$root\dist\AION2实时翻译\使用说明.txt" -Force
Copy-Item "$root\src\AionTranslator.UI\bin\Release\net10.0-windows\win-x64\publish\AION2实时翻译.exe" "$root\本地版\" -Force   # 本地自用副本

Remove-Item "$root\dist\AION2实时翻译.zip" -Force -ErrorAction SilentlyContinue
Compress-Archive -Path "$root\dist\AION2实时翻译\*" -DestinationPath "$root\dist\AION2实时翻译.zip" -CompressionLevel Optimal
```

分发目录必须包含：`AION2实时翻译.exe`、`使用说明.txt`、`prompt\system-prompt.txt`。
**不得**包含任何第三方 DLL 或外部工具（历史上有过一个第三方读取组件的加载探针，已彻底删除，见 §9）。

## 5. 游戏内存读取（最核心，也是最容易坏的部分）

### 5.1 定位链路

```
EnumWindows → class == "UnrealWindow" → pid
  → 校验进程 exe 名为 AION2.exe，并对其磁盘文件算 SHA256
  → 匹配 ChatBuildProfile（见 5.2）
  → EnumProcessModules 拿到 AION2.exe 真实装载基址
  → 按 RVA 读指针链 → 得到聊天系统对象 → 读记录数组
```

### 5.2 已验证版本表（`ChatBuildProfiles.cs`）

| Profile | exe SHA256 | 说明 |
|---|---|---|
| `Steam-20261024` | `ce978f75…d9b107` | 旧版本，RVA 一组 |
| `Steam-20261028` | `7dfbcde8…5389530` | 当前验证版本（RVA 一组） |

每个 profile 含 12 个 RVA：`Weak/Chunks/Count/Class/Vtable/Data/Controller/PropertyVtable/RootGetter/ChatName` 等，
记录布局固定为「A 版」：

```
RecordBytes  = 336    # 每条记录步长
BodyOffset   = 16     # 正文 FString（int32 长度 + UTF-16 数据）
SenderOffset = 40     # 说话人
ChannelOffset= 120    # 频道号（byte）
MaximumRecordsPerChannel = 120
```

指针链要点（逆向结论，`docs/快捷发送方案.md` 有更细的过程记录）：
- 聊天对象内部有 `{ptr, ptr-16}` 两段引用；
- 频道表在 `chat + 48`；
- 记录数组按 stride 336 遍历，长度字段是 UTF-16 字节数还是字符数需按实际校验（读到乱码就说明偏移错了）。

### 5.3 游戏客户端更新后怎么修

1. 用 `tools/ChatScan` 的 `dumpimage` 模式把模块内存镜像落到 `out\image.bin`（**需管理员**）；
   - 客户端有壳（`.ncg0`~`.ncg6` 段），静态文件里查不到 vtable，必须用运行时镜像；
2. 用 `ChatBuildProfiles` 里的特征码（`RootGetterPattern`、`VtablePattern`、`DataPattern`、
   `PropertyVtablePattern`）在镜像里重新定位，得到新 RVA；
3. 用 `tools/re/chat_vtable.py`（capstone + pefile）给候选 vtable 打分，选命中聊天相关虚函数的那个；
4. 新增一条 `ChatBuildProfile`（Name/SHA256/ImageBytes/各 RVA），不要改动旧条目；
5. 用 `tools/ChatScan` 的 `scan`/`peek` 验证能解出中文频道与正文；
6. 打包前务必确认 `TryAttach` 的 `Status` 文本里版本名正确。

> 注意：`Aion2GameReader.TryAttach` 只用「窗口类名 + 进程名 + SHA256」判定，**不做**内存特征扫描的兜底。
> 版本不匹配就明确报错，不要静默降级——这是刻意设计（避免读错内存显示乱码）。

### 5.4 权限硬约束

- 游戏客户端**提权运行**（带 `NCGuard`），普通权限进程 `OpenProcess(VM_READ)` 直接 `error=5`；
- 因此本程序必须 `requireAdministrator`；
- 反之，普通权限的命令行工具**碰不到**这个游戏：`PostMessage` 会被 UIPI 丢弃、`SendInput` 无效、`PrintWindow` 失败（已实测）。

## 6. 翻译链路

`MainWindow.OnIncoming` → 过滤频道 → `_queue` → `FlushAsync()`：

1. 从队列取 `BatchSize`（默认 3）条；
2. **目标语言同语言的消息不送翻译**（`AlreadyInTarget`）——中文消息原样显示，不花额度；
3. 其余打包成 `ChatLine` 交给 `OpenAiTranslator.TranslateAsync(lines, ct, TargetLanguage, Provider)`；
4. 结果写回对应的 `ChatRow.Translation`，失败显示 `（翻译失败：原因）`；
5. `SharedRows` 超过 `MaxHistory` 就从头部丢最旧的（**只影响显示，不影响已翻译内容**）。

`OpenAiTranslator` 要点：
- OpenAI 兼容 `/chat/completions`；
- 多 Key 轮换、并发上限 `MaxConcurrency`、超时 `TimeoutSeconds`、重试 `MaxRetries`；
- 提示词 = `prompt/system-prompt.txt` + `Glossary` + `ExtraPromptLines`；
- 「B站公共接口」是 `Keyless=true` 的无 Key 通道（默认），外文→中文、中文→外语都通。

### 启动时会不会把几百条历史全翻一遍？

- **不会**。`GameChatSource.ReadViaReader` 第一轮（`_primed` 尚未置位时）**每频道只取最近 8 条**：
  ```csharp
  messages = messages.GroupBy(m => m.ChannelCode)
      .SelectMany(g => g.Skip(Math.Max(0, g.Count() - 8)));
  ```
  之后每 400 ms 只推新出现的记录（`_seen` 去重，最多记 4096 个 key）。
- 也就是说：启动瞬间最多 `8 × 频道数` 条进入翻译队列（实测 3 个频道 → 约 19 条、约 6 次请求）。
- 已知可优化点（**尚未实施**）：首轮那 8 条多为历史残留，可以改成「首轮只登记已读、不翻译」。

## 7. UI 行为规格（改动必须遵守）

### 7.1 主窗口

- 启动后**自动缩进托盘**（`Loaded` 里 `HideToTray()`），桌面和任务栏都不出现；
- 点 × / 最小化 → 收进托盘，不退出；退出走托盘右键菜单；
- **F10** 唤出主界面：`Show()` → `WindowState.Normal` → `ShowInTaskbar=false` → `Topmost=true` → `Activate()`
  - `Activate()` 不能省：无边框全屏的游戏会把未激活的窗口盖住（历史 bug）；
  - `ShowInTaskbar=false` 也不能省：进任务栏会把桌面/任务栏顶出来；
- **F9** 显示/隐藏悬浮窗的手动条。

### 7.2 悬浮窗

- 默认位置：屏幕左侧、垂直居中；可拖动，位置记忆；
- 默认**不做**鼠标穿透（`ClickThrough=false`），用户想穿透自己去设置里开；
  手动条打开时会临时取消穿透（否则点不到输入框）；
- 玩家 ID 颜色 = 频道：
  ```
  世界 / 种族            → 黄
  附近（一般、呐喊）      → 白（主界面白底，显示为浅灰蓝）
  组队类（小队、部队、副本、军团） → 蓝
  其它（系统/NPC/活动）  → 灰蓝
  ```
- 字号 `OverlayFontSize`、透明度 `OverlayOpacity` 可在设置里调。

### 7.3 手动条（F9 调出）

布局（从上到下）：

```
[快捷用语按钮行]  ← 设置里有内容才显示，没有就整行隐藏（界面上不出现“快捷用语”字样）
[输入框]                [语言下拉]
[译文框（只读）]         [翻译]
                        [复制 / 发送]
```

- **快捷用语**：设置里「快捷用语（每行一条）」→ `Settings.QuickPhrases`；
  `OverlayWindow.RefreshQuickPhrases()` 生成按钮；点一下 = **填进输入框 + 复制到剪贴板**（英文快捷语无需再翻译）；
- **按钮逻辑**（`RefreshSendButton()` / `CanSendToGame`）：
  | `OneKeySend` | 目标语言 | 按钮文字 | 行为 |
  |---|---|---|---|
  | false | 任意 | 复制 | 译文进剪贴板 |
  | true | 英语 | 发送 | 投递字符进游戏聊天框 + 尝试回车 + 同时静默复制 |
  | true | 其它 | 复制 | 译文进剪贴板 |
  - 语言下拉一变就立即刷新按钮文字（`LangBox.SelectionChanged`）；
  - 设置保存后主窗口调用 `_overlay.RefreshSendButton()` 与 `RefreshQuickPhrases()`。

### 7.4 设置窗口

- **绝对不能**给 SettingsWindow 加 `WS_EX_NOACTIVATE` / `ShowActivated=false`：
  那样 WPF 下拉框弹不出来、按钮点不动（历史踩坑）；
- 保持 `Topmost=true`、正常激活，关闭时把焦点还给原窗口。

## 8. 把文字送进游戏聊天（`ChatSender.cs`）——能力边界

这块是最容易被误解的部分，**按实测结论写代码，不要凭想象加“自动发送”**。

### 8.1 已实测成立

| 动作 | 手段 | 结果 |
|---|---|---|
| 把 ASCII 文字打进聊天输入框 | `PostMessage(WM_CHAR)` 逐字，间隔 22–40 ms 随机 | ✅ 字确实进框 |
| 打开游戏聊天框 | 任何投递 / `SendInput` | ❌ 无效（回车、字符都试过） |
| 让游戏“回车发送” | 投递 `WM_KEYDOWN VK_RETURN`（含带扫描码 lParam）、`WM_CHAR 0x0D` | ❌ 字留在框里，发不出去 |
| 真实注入按键（`SendInput`，含 Unicode） | `KEYEVENTF_UNICODE` | ❌ 游戏完全忽略（框开着、光标闪也打不进字） |

### 8.2 结论（对外必须这么描述）

- **打开聊天框只能玩家自己按一次回车**；
- 程序能做的是：玩家开框后，点「发送」→ 逐字把译文打进框里 → **同时把译文放进剪贴板**；
- 最后那一下回车由玩家按（或玩家自己在框里回车）。
- 因此 UI/文案/说明一律写成「先打开聊天框 → 点发送 → 按回车发出」，**不要写“程序自动发出”**。

### 8.3 非英文的处理

- 逐字输入只对 ASCII 可靠；中文/日文/韩文会变方框；
- `ChatSender.HasCjk()` 判定含 CJK/全角标点时 → 退回“复制”；
- `NormalizeForGame()` 把弯引号 `“ ”`、破折号 `—`、省略号 `…`、`·` 换成 ASCII，避免英文译文被误判成“非英文”。

### 8.4 曾经失败的路子（别重复踩）

- `SendInput` 想开聊天框：焦点在自己窗口上时，按键打进了自己；即便切前台成功，游戏也忽略注入输入；
- 想靠内存覆写输入框（`tools/ChatScan` 的 `overwrite` 模式）：能写进去但界面不刷新，IME/渲染层有缓存，放弃；
- 想用驱动级 HID 注入（罗技 G HUB / Interception）：技术上可行（付费同类工具就是这么干的），
  但需要用户装驱动，**作者决定不做**，也不要求用户装。

- 生成器：`tools/icons/gen_teru.py`（Pillow，纯几何绘制，9 种风格：sunny / sky / candy / neon / crayon / matcha / sticker / glass / mint）
- 运行：
  ```powershell
  python aion2\tools\icons\gen_teru.py     # 需要 Pillow
  ```
  输出到 `aion2/icons/`：`<name>.png`(512)、`<name>-256.png`、`<name>.ico`(16/24/32/48/64/128/256)、
  `00-preview.png`（9 宫格）、`00-small-sizes.png`（16/24/32/48 真实像素对照）
- 当前采用：**02-sky**（`icons/app.ico` 即它的副本；`csproj` 的 `<ApplicationIcon>` 指向 `..\..\icons\app.ico`）
- 换图标的流程：把选中款复制成 `icons\app.ico` → 重新 build/publish → 托盘图标通过
  `Icon.ExtractAssociatedIcon(exePath)` 自动跟着变，WPF 窗口图标也取自程序集。

## 11. 诊断工具（`tools/`）

| 工具 | 用途 | 注意 |
|---|---|---|
| `ChatScan` | 内存扫描/指针搜索/镜像 dump/覆写测试（`scan\|ptrscan\|dumpfile\|overwrite\|peek\|dumpimage`） | 必须管理员，一次全量扫描约 12 GB 读取、64–82 s |
| `ChatProbe` | 按键/字符投递实验（A~F 脚本） | 会等游戏成为前台再动作；仅诊断用 |
| `GameShot` | `PrintWindow` 截游戏画面 | 对本游戏返回 false（D3D），别指望 |
| `WinEnum` | 枚举 UnrealWindow/进程 | 排查“找不到游戏窗口” |
| `tools/re/*.py` | vtable 打分、字符串提取 | 需 capstone/pefile |

沙箱/权限提醒：这些 `.cmd` 需要用户手动以管理员运行（UAC 不能由脚本代点）。

## 12. 自检清单（发版前）

1. `dotnet build` 零 error；
2. `dotnet publish` 产物存在，大小 ≈ 72 MB；
3. 起程序：自动进托盘，任务栏无图标；
4. F9 出手动条（无快捷用语时那行不显示）；F10 能唤出主界面且**不把桌面/任务栏顶出来**；
5. 设置里勾「一键发送」→ 语言选英语 → 按钮文字变「发送」；切日语 → 变「复制」；
6. 开始翻译：列表出译文；中文消息原样显示不送翻译；
7. `dist\使用说明.txt` 与 `dist\AION2实时翻译\使用说明.txt` 内容一致；
8. exe 内不含任何第三方名称 / 路径 / 加载逻辑字符串；
9. 记录 exe 的 SHA256 便于用户核对。
